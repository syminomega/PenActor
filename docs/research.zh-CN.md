# 保留的研究记录

[English](research.md) | 简体中文

以下内容是历史观察，不是当前兼容性保证，也不是已实现功能清单。
本文合并了早期输入、交付频率和 Sidecar 研究记录；已过时的逐版本实现计划已清理。

## Pencil 起笔压力（2026-10-21）

用户在 Photoshop 2026 中观察了三笔 Sidecar/Pencil 输入，AppKit 起始压力均为 `0.0784`。
后续数值有时会先下降再上升，其中一组下降到 `0.0118`。
这些数据来自保留四位小数的界面读数，而非完整精度的 JSON 采集。
采集代码没有填充该初始值。现有证据不能确定原因来自硬件、Sidecar、输入处理还是笔刷行为。
首次接触压力非零本身并不构成错误。

用户反馈 PenActor 0.2.0 的静态压力重映射影响了绘画响应。
当时没有系统记录应用、笔刷和曲线组合。该反馈不能验证缓冲笔锋效果，也不能证明起笔压力问题
已经修复。后续可在相同笔刷动态和笔锋设置下采集配对的 PS/CSP 日志进行对照。

## 事件交付频率（2026-10-26）

此前对用户提供日志的分析，提取完整按下到抬起笔画内的 `leftMouseDragged` 间隔，
排除了悬停和跨笔间隔：

| AppKit 观察结果 | Sidecar/Pencil | Wacom Intuos Pro |
| --- | ---: | ---: |
| 完整笔画数 | 3 | 1 |
| 拖动事件数 | 228 | 423 |
| 汇总交付频率 | 83.75/s | 106.18/s |
| 平均间隔 | 11.94 ms | 9.42 ms |
| 中位间隔 | 12.34 ms | 7.54 ms |
| P95 间隔 | 21.16 ms | 13.19 ms |
| 最大间隔 | 31.57 ms | 42.64 ms |
| 超过 16.67 ms 的间隔 | 36/225 | 12/422 |

Pencil 在 Photoshop 中运行，开启了映射和入锋；Wacom 在本地测试，映射关闭。
条件不同，不能把差异单独归因于硬件、Sidecar 或映射开销。
两段保留的 Pencil tap 事件显示约 238 events/s，但旧日志缺少 tap 类型码，无法排除伴随包。
两类测量都不能确定硬件采样率。AppKit 事件合并、界面刷新率与硬件采样率是不同概念。

可使用 `scripts/analyze-pen-log.py` 和原始日志重新计算。
个人原始日志有意排除在仓库之外。

## Sidecar 手指长按（2026-10-22）

用户反馈在 Sidecar 屏幕上绘画时，停留的手指可能打开 Photoshop 的画笔上下文菜单，
并有时导致交互卡住。实验性的 annotated-session tap 能观察到普通鼠标或触控板右键，
但没有观察到 Sidecar 长按。该实验与未经验证的平滑控件已在 0.6.3 中从交付代码移除。

此前研究找到了目标应用内部视图和手势识别器的控制入口，但未找到受支持的公开跨进程开关，
能够在保留缩放与旋转的同时选择性禁用 Sidecar 长按。
应用的 `NSIsTouchNative` 声明不是外部可控制的独立手势开关。
按 PID 的专属 tap 对照尚未验证。不能把屏蔽所有右键或发送 Escape 描述为该问题的已验证修复。

后续设备测试应记录系统和应用版本、笔与手指的接触顺序、按下、抬起与取消事件、应用焦点变化、
普通鼠标输入及多指行为。将实验控件重新加入应用前，需要真实设备的观察证据。
