# 使用与诊断

[English](usage.md) | 简体中文

## 服务与权限

通用设置控制启动时是否开始监听、是否打开设置窗口。关闭设置后服务继续运行。
每次重启应用后，映射始终处于暂停状态；准备好后需手动启用已保存的配置。
**⌘⇧R** 暂停全部映射，**⌘⇧P** 启动或停止输入服务。

未授予输入监控权限时，本地笔输入测试仍可能工作。全局观察使用输入监控权限，主动压力映射
需要辅助功能权限。请求权限按钮会打开对应的系统隐私设置页，失败时回退到隐私设置总览。
如果列表中没有应用，请添加已安装的 `PenActor.app`，并按系统提示重新启动。
之后回到通用页重新检查权限。

应用的安装路径、bundle ID 和签名身份会影响权限识别。旧身份对应的条目处于开启状态，
并不能证明当前构建已获授权。更新本地构建时，请参阅[签名说明](development.zh-CN.md#签名)。

## 设备默认设置与配置

1. 让笔进入感应范围并落笔，使 PenActor 能够识别设备。
2. 在配置页选择设备，可按需设置显示名称。
3. 保存设备默认压力曲线和入锋、出锋设置。
4. 创建或选择命名配置，添加目标应用并保存。
5. 在服务运行且权限可用时启用配置。

每台设备有独立的默认设置。应用规则可以继承设备默认值，分别覆盖曲线、入锋、出锋，
或保持输入透传。已保存设置的变化从下一笔开始生效。每台设备同时只能启用一个配置。
未知设备和不在所选配置目标范围内的应用保持透传。清空调试历史不会删除配置或设备名称。

曲线在可编辑控制点之间进行单调插值。入锋根据累计屏幕距离或经过时间渐入压力，
距离和时间任一先达到上限即结束入锋。出锋延迟匹配的笔事件，并在抬笔后渐隐仍在队列中的尾部。
入锋和出锋默认都关闭。

出锋时长同时也是基础输入延迟，可调范围为 10–200 ms；队列顺序和调度可能增加额外延迟。
很短的笔画在入锋与出锋重叠时可能明显变淡；应用不会合成静止压力采样。
建议先对照关闭笔锋、仅启用入锋、再启用出锋的效果，再决定参数。
停止或禁用映射可能提前结束正在缓冲的笔画。

## 调试与测试页面

调试页显示实时数值、元数据、最近事件和独立的 tap 诊断。压力条直接跟随最新读数。
输入停止后历史记录仍保留；没有事件不能证明设备已断开。自动选择会在活动笔变化时切换设备，
也可关闭该选项进行手动观察。

压力是归一化的系统值，而非物理力度。倾斜是归一化值，旋转以度为单位；绝对坐标属于数位板
坐标空间，屏幕坐标为全局屏幕点坐标。缺失压力与零压力不同。能力位表示驱动声明，
不能证明相应硬件功能已经正常工作。

测试页使用本地笔事件绘制随压力变化的线条。使用 Sidecar 时，请将窗口移到 iPad 上。
Pencil 双击与挤压回调仅适用于此窗口，不归属于某一支笔。AppKit 与 SwiftUI 对同一次
双击的报告会配对去重。SwiftUI Pencil 回调要求 macOS 14.5；更早的受支持系统仍可使用
AppKit `changeMode`。

## 持久化

文件位于 `~/Library/Application Support/PenActor/`：

| 文件 | 当前 schema | 内容 |
| --- | --- | --- |
| `profiles.json` | 6 | 配置 ID、名称、设备身份与应用规则 |
| `defaults.json` | 4 | 设备显示名称和默认配置 |

读取器支持配置 schema 1–6 和默认设置 schema 1–4。
迁移前会将已有文件备份到 `Backups/device-scoped-<UUID>/`。
旧版已移除的 smoothing 字段会被丢弃，曲线和笔锋设置保留。
遇到不支持的未知数据或无效配置时，程序阻止写入，不覆盖原文件。
已启用配置的 ID 不会持久化。

## JSON 导出

在调试页使用**导出 JSON**。文件是点击按钮时的快照，按采集顺序从旧到新排列，包含全部设备，
不局限于当前选择的设备。保存面板打开后到达的事件不会进入该快照。
导出使用 schema 4、格式化的 UTF-8 JSON、未按界面精度舍入的数值，以及精确到毫秒的
UTC ISO 8601 接收日期。

| 字段 | 含义 |
| --- | --- |
| `events` | 最多 500 条保留的 AppKit 事件，含原生类型码、采集时身份、采样、屏幕坐标和前台上下文 |
| `devices` | 已解析身份、会话 ID，以及最近元数据和感应状态 |
| `totalObservedEvents`, `retainedEventCount`, `discardedEventCount` | 采集覆盖情况；更早事件可能已被淘汰 |
| `profiles`, `mapping.defaults` | 导出时的已保存配置 |
| `mapping.diagnostics` | 最多 500 条独立 tap 诊断，包含输入输出压力、路由、配置、笔锋和派发方式 |
| `mapping.bufferedEventCount` | 仍在等待输出的事件数量 |
| `pencilGestures` | 本地手势累计摘要 |

系统事件时序分析使用 `timestamp` 的差值；`receivedAt` 记录本地接收时间。
`sample.pressure = null` 表示压力不可读取，`0` 表示有效的零压力。
proximity 事件不包含 sample。

AppKit 观察值可能已经包含映射后的压力。tap 诊断分别记录处理前后的压力，不与 AppKit
事件逐条配对。输出值在写入后读回，可能包含量化误差。诊断说明程序准备输出什么，
不代表目标应用已经确认接收。

日志可能包含可识别设备的硬件元数据、应用上下文和绘画位置。
文件保存在本地，不会自动上传。导出文件和 `Logs/` 已被 Git 忽略。
可使用以下命令离线分析时序：

```sh
python3 scripts/analyze-pen-log.py /path/to/PenActor-log.json
```
