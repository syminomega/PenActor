# PenActor 0.5：以设备为中心的配置

设置分为「通用、配置、调试、测试」，启动时默认进入配置页。通用页只管理程序启动、输入服务和权限，不再提供跨设备压力曲线，也不再有独立的应用页。菜单栏后台运行方式保持不变；没有额外系统服务或登录启动项。

## 日常流程

1. 在「配置」页左侧选择已观察到的设备。设备名称可以单独修改，与配置名称互不影响；名称不参与硬件身份匹配。
2. 「编辑」菜单选择「设备默认」，调整这台设备的压力曲线、入锋与出锋，并保存。这组默认值不会影响其他设备，也不会自动启用映射。
3. 为设备新增一个或多个配置，命名后添加一个或多个生效应用。应用从运行程序选择，或浏览 `.app`，按真实 bundle ID 保存。
4. 新添加应用默认「继承设备默认」，通常无需再设置曲线。只有需要例外时，关闭继承或点击该行设置按钮，在弹窗中编辑「单独覆盖」。也可选择「不映射」保留系统压力。
5. 保存并启用配置。首次启用后让笔离开再进入感应范围，以建立 tap 会话关联。

每台设备同时启用一个配置；不同设备可以同时启用各自的配置。选择另一台设备或配置进行编辑，不改变已经启用的配置。未列入已启用配置的应用、未识别设备和未启用设备保持透传。

## 继承和覆盖

一个应用的最终行为只在**所属设备和当前启用配置**中解析：

| 应用行模式 | 行为 |
| --- | --- |
| 继承设备默认 | 使用这台设备保存的压力曲线与入锋 / 出锋，设备默认保存后自动跟随 |
| 单独覆盖 | 使用这个配置中该应用的完整自定义参数，其他应用和设备不受影响 |
| 不映射 | 保留系统输入，不应用曲线或入锋 / 出锋 |

这些设置不是叠加处理，曲线只应用一次。切换回继承会保留先前覆盖值，便于再次使用；覆盖编辑器提供「复制当前设备默认」。同一软件在不同配置或不同设备中有独立的应用行。

例如，Pencil 的设备默认可以使用轻压增强，配置中 PS 与 CSP 都继承它；若只有 PS 需要入锋修正，只覆盖 PS。Wacom 的设备默认仍可保持线性或完全不启用。

界面采用显式保存。修改配置、设备默认或应用继承关系，从下一笔生效；当前笔画锁定开始时的参数。禁用、暂停全部映射和停止服务立即恢复透传。切换设备或配置时，如有未保存内容，会提示放弃或继续编辑；临时切换到通用 / 调试等页会保留编辑草稿。

## 窗口与信息密度（0.5.5）

各页共用窗口宽度（默认 860 点、最小 820 点），手动调整宽度后切换页面不改变宽度。通用与调试页按当前内容自动计算高度，不使用整页滚动；配置、测试默认内容高度分别为 600、620 点，并在本次运行中记住手动调整的高度。切换时固定窗口顶部，使用约 0.2 秒系统窗口动画调整高度。通用页可能新增配置错误提示；调试页在收到采样、硬件元数据、映射诊断或展开说明时会增加内容并自动调整高度，普通数值更新不触发重复缩放。开启系统「减少动态效果」时直接调整，已最大化时不强制缩小。

配置页的保存、启用和删除位于固定底部操作区，长应用列表或曲线编辑内容滚动时仍可操作。曲线和入锋 / 出锋编辑器缩紧，滑块标签、控件和数值排列在同一行，隐藏下方密集刻度；调整仍按原先步长取整。

调试页分为「实时数值、设备详情、事件记录」三个视图，避免所有信息堆叠成一条长页面。实时视图并排等高显示紧凑数值与压力趋势，下面是映射状态；匹配详情、监听说明和事件上下文按需展开。设备详情以两列完整保留标识和硬件信息；事件列表使用可滚动表格占据剩余空间。读数的缺失 / 支持状态、导出字段及缓存上限保持不变。

测试页不使用滚动容器，标题、工具按钮、说明和手势区完整显示；窗口高度变化只伸缩画布。Pencil 手势先展示计数和当前状态，来源、最近时间及使用说明可展开查看，展开时同样由画布让出空间。

## 设备名称与身份

设备别名保存在设备设置中，重启、重连或删除最后一个配置后仍然保留。稳定匹配键与名称独立，改名不影响重连识别。没有稳定元数据的临时会话不能创建持久配置。Sidecar 仍只能按系统报告的型号归组，改名不能区分多支同型号 Pencil。

## 文件与旧版迁移

- `~/Library/Application Support/PenActor/profiles.json`：schema 4。保存配置 UUID、名称、设备身份及独立的 `applicationRules`，兼容读取 schema 1～3。
- `~/Library/Application Support/PenActor/defaults.json`：schema 2。`devices` 保存每台设备的名称和默认参数。
- `Backups/device-scoped-<UUID>/`：首次需要迁移时，先备份原来的两个文件。
- 程序启动行为和调试设备自动切换仍保存在应用偏好设置中。

迁移用设备第一份已有配置的参数初始化设备默认；原来继承全局的设备以旧全局值初始化。随后逐一解析每份旧配置对每个目标应用实际生效的参数：与设备默认相同则设为继承，不同则保存为覆盖，旧应用透传设为不映射。配置 UUID、配置名称、稳定设备身份和目标范围保持不变。保存中保留的旧 `global / applications`、`curve / taper / usesDefaults / targetBundleIDs` 字段仅用于兼容，不参与新配置的设备间继承。

两个 JSON 各自采用原子写入；它们不构成跨文件事务。迁移先写设备默认再写配置，可在中断后重复执行；原文件备份用于恢复。读取或迁移失败时阻止配置写入和映射启用，以免覆盖损坏文件。迁移不是自动启用：重启后映射仍关闭。

导出日志继续使用 schema 2；`profiles[].applicationRules` 和 `mapping.defaults.devices` 共同说明当时保存的配置。清空调试记录不删除配置或设备名称。

## 后台与验证

菜单栏可打开设置、直接进入调试 / 测试、启停服务、暂停全部映射和退出。关闭窗口继续后台运行，从菜单栏退出才停止服务。`⌘⇧R`、`⌘⇧P` 属于应用菜单快捷键，并非跨应用全局热键。

自动化覆盖设备隔离、应用覆盖、未列设备 / 应用透传、笔画锁定、设备重命名、旧版迁移等价性及可重复性、迁移备份、损坏文件保护和生命周期。原生页面与覆盖编辑器有离屏渲染检查；真实菜单栏 / 弹窗点击与 Sidecar、PS、CSP 绘画仍待实机验证。指定应用屏蔽 Sidecar 触摸继续保留为 TODO。

## 随航触摸长按右键实验（0.5.6）

通用页增加「屏蔽触摸长按右键（实验）」。默认关闭，重启不恢复开启；目标应用列表保存在偏好设置中，初始仅包含 `com.adobe.Photoshop`，可从运行应用或 `.app` 添加其他应用。需要输入服务运行和辅助功能权限，与压力映射配置独立。

当前只过滤目标 PID 对应所选 bundle ID 且鼠标 subtype 为公开 `.touch` 标记的右键按下，不依据前台应用、iPad 区域或最近 Pencil 活动猜测来源。不按时长自行识别长按，因此其他同样带 touch 标记的右键也可能被过滤。Control 修饰的按下、普通鼠标和 tablet subtype 不参与匹配；缩放、旋转、滚动不在这个独立 tap 的事件掩码内。

拦截按下后，以 source PID 与 event number 跟踪拖动和抬起；关闭开关、移除应用或目标改变仍完成已有匹配序列的收尾，不拦截此前已透传按下的释放。无事件编号且抬起也无 touch 标记时采用透传，避免吞掉实体鼠标释放。清空诊断不重置进行中的匹配序列。停止服务或退出会销毁此 tap；其已过滤的按下没有送入应用，不额外注入补偿右键。

面板显示观察右键数、拦截按下数和拦截事件数。导出 JSON 的可选 `touchBlocking` 字段保存状态、目标列表及独立的最近 500 条右键记录：类型、时间、subtype、event number、源与目标 PID、目标 bundle ID 和过滤结果。不记录键盘文本。关闭过滤后 tap 暂保留以收尾和观察，停止服务时停止采集；重启默认不创建该 tap。

这是等待实机验证的候选过滤器，不代表已证实识别随航来源。测试时在 PS 分别执行长按、Pencil 加手指长按、正常右键，以及双指缩放／旋转／滚动。如仍弹出画笔菜单，记录计数变化并导出 JSON：观察为 0 可能是事件未经过此 tap；观察增加而拦截为 0 时需检查 subtype 和目标 PID，不自动退化为屏蔽所有右键。
