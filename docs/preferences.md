# PenActor 0.5：以设备为中心的配置

设置分为「通用、配置、调试、测试」，启动时默认进入配置页。通用页只管理程序启动、输入服务和权限，不再提供跨设备压力曲线，也不再有独立的应用页。菜单栏后台运行方式保持不变；没有额外系统服务或登录启动项。

## 日常流程

1. 在「配置」页左侧选择已观察到的设备。设备名称可以单独修改，与配置名称互不影响；名称不参与硬件身份匹配。
2. 「编辑」菜单选择「设备默认」，调整这台设备的压力曲线、入锋与出锋，并保存。这组默认值不会影响其他设备，也不会自动启用映射。
3. 为设备新增一个或多个配置，命名后添加一个或多个生效应用。应用从运行程序选择，或浏览 `.app`，按真实 bundle ID 保存。
4. 新添加应用默认「继承设备默认」，通常无需再设置曲线。只有需要例外时，关闭继承或点击该行设置按钮，在弹窗中编辑「单独覆盖」。也可选择「不映射」保留系统压力。
5. 保存并启用配置。首次启用后让笔离开再进入感应范围，以建立 tap 会话关联。

每台设备同时启用一个配置；不同设备可以同时启用各自的配置。选择另一台设备或配置进行编辑，不改变已经启用的配置。未列入已启用配置的应用、未识别设备和未启用设备保持透传。

## 继承和覆盖

一个应用的最终行为只在**所属设备和当前启用配置**中解析：

| 应用行模式 | 行为 |
| --- | --- |
| 继承设备默认 | 使用这台设备保存的压力曲线与入锋 / 出锋，设备默认保存后自动跟随 |
| 单独覆盖 | 使用这个配置中该应用的完整自定义参数，其他应用和设备不受影响 |
| 不映射 | 保留系统输入，不应用曲线或入锋 / 出锋 |

这些设置不是叠加处理，曲线只应用一次。切换回继承会保留先前覆盖值，便于再次使用；覆盖编辑器提供「复制当前设备默认」。同一软件在不同配置或不同设备中有独立的应用行。

例如，Pencil 的设备默认可以使用轻压增强，配置中 PS 与 CSP 都继承它；若只有 PS 需要入锋修正，只覆盖 PS。Wacom 的设备默认仍可保持线性或完全不启用。

界面采用显式保存。修改配置、设备默认或应用继承关系，从下一笔生效；当前笔画锁定开始时的参数。禁用、暂停全部映射和停止服务立即恢复透传。切换设备或配置时，如有未保存内容，会提示放弃或继续编辑；临时切换到通用 / 调试等页会保留编辑草稿。

## 窗口与信息密度（0.5.11）

顶部页面切换采用统一紧凑标题栏中的单行图标＋文字分段控件，不再使用图标在上、文字在下的宽工具栏。各页共用窗口宽度（默认 860 点、最小 820 点），手动调整宽度后切换页面不改变宽度。通用与调试页按当前内容自动计算高度，不使用整页滚动；配置、测试默认内容高度分别为 600、620 点，并在本次运行中记住手动调整的高度。切换时固定窗口顶部，使用约 0.2 秒系统窗口动画调整高度。通用页可能新增配置错误提示；调试页在收到采样、硬件元数据、映射诊断或展开说明时会增加内容并自动调整高度，普通数值更新不触发重复缩放。开启系统「减少动态效果」时直接调整，已最大化时不强制缩小。

配置页的保存、启用和删除位于固定底部操作区，长应用列表或曲线编辑内容滚动时仍可操作。曲线和入锋 / 出锋编辑器缩紧，滑块标签、控件和数值排列在同一行，隐藏下方密集刻度；调整仍按原先步长取整。

调试页分为「实时数值、设备详情、事件记录」三个视图，避免所有信息堆叠成一条长页面。实时视图并排等高显示紧凑数值与压力趋势，下面是映射状态；匹配详情、监听说明和事件上下文按需展开。设备详情以两列完整保留标识和硬件信息；事件列表使用可滚动表格占据剩余空间。读数的缺失 / 支持状态、导出字段及缓存上限保持不变。

测试页不使用滚动容器，标题、工具按钮、说明和手势区完整显示；窗口高度变化只伸缩画布。Pencil 手势先展示计数和当前状态，来源、最近时间及使用说明可展开查看，展开时同样由画布让出空间。

## 设备名称与身份

设备别名保存在设备设置中，重启、重连或删除最后一个配置后仍然保留。稳定匹配键与名称独立，改名不影响重连识别。没有稳定元数据的临时会话不能创建持久配置。Sidecar 仍只能按系统报告的型号归组，改名不能区分多支同型号 Pencil。

## 文件与旧版迁移

- `~/Library/Application Support/PenActor/profiles.json`：schema 6。保存配置 UUID、名称、设备身份及独立的 `applicationRules`，兼容读取 schema 1～5。
- `~/Library/Application Support/PenActor/defaults.json`：schema 4。`devices` 保存每台设备的名称和默认参数。
- `Backups/device-scoped-<UUID>/`：首次需要迁移时，先备份原来的两个文件。
- 程序启动行为和调试设备自动切换仍保存在应用偏好设置中。

迁移用设备第一份已有配置的参数初始化设备默认；原来继承全局的设备以旧全局值初始化。随后逐一解析每份旧配置对每个目标应用实际生效的参数：与设备默认相同则设为继承，不同则保存为覆盖，旧应用透传设为不映射。配置 UUID、配置名称、稳定设备身份和目标范围保持不变。保存中保留的旧 `global / applications`、`curve / taper / usesDefaults / targetBundleIDs` 字段仅用于兼容，不参与新配置的设备间继承。

两个 JSON 各自采用原子写入；它们不构成跨文件事务。迁移先写设备默认再写配置，可在中断后重复执行；原文件备份用于恢复。读取或迁移失败时阻止配置写入和映射启用，以免覆盖损坏文件。迁移不是自动启用：重启后映射仍关闭。

导出日志使用 schema 4；`profiles[].applicationRules` 和 `mapping.defaults.devices` 共同说明当时保存的配置。清空调试记录不删除配置或设备名称。

## 后台与验证

菜单栏可打开设置、直接进入调试 / 测试、启停服务、暂停全部映射和退出。从 0.5.7 起，设置窗口打开时显示 Dock 图标并进入 ⌘Tab 应用切换；最小化或切换到其他应用时保留 Dock 入口，再点 Dock 可恢复设置窗口。关闭设置窗口后隐藏 Dock 图标并继续后台运行，从菜单栏退出才停止服务。`⌘⇧R`、`⌘⇧P` 属于应用菜单快捷键，并非跨应用全局热键。

自动化覆盖设备隔离、应用覆盖、未列设备 / 应用透传、笔画锁定、设备重命名、旧版迁移等价性及可重复性、迁移备份、损坏文件保护和生命周期。原生页面与覆盖编辑器有离屏渲染检查；真实菜单栏 / 弹窗点击与 Sidecar、PS、CSP 绘画仍待实机验证。指定应用屏蔽 Sidecar 触摸继续保留为 TODO。


## 操作层级（0.5.10）

页面底部的操作区只放当前设备／配置的保存、启用或删除，主要操作保持在右侧。全窗口最底部采用淡色状态条：左侧是全局映射状态及带背景和边框的次要按钮「暂停全部映射」，右侧是输入服务状态，避免暂停与上方保存按钮上下堆叠。没有已启用或启动中的映射时，暂停按钮禁用。菜单栏入口和 `⌘⇧R` 保留；暂停不停止输入服务，也不修改触摸过滤实验。

## 授权入口（0.5.9）

输入监控与辅助功能按钮调用系统请求后，均显式尝试打开对应隐私设置页。跳转失败时退回隐私概览或显示手动路径；进入页面并不等于已授权。列表缺少应用时通过 + 添加固定安装路径，按系统提示重启后重新检查。旧版本更新后反复授权与原 ad-hoc 签名有关；0.5.9 起本机已配置稳定开发签名，详情和稳定签名构建方式见 [授权与签名](permissions-and-signing.md)。

## 草稿与焦点（0.5.11）

切换设备或配置前结束文本编辑，并清除名字输入框焦点；不同设备和配置使用独立编辑视图身份。输入框发出相同值的回调、仅取得或失去焦点，不再标记修改。草稿与加载／保存时的基准值比较，改回原值也恢复为未修改。旧输入框延迟提交的设备或配置名称会核对原身份，不能覆盖新选择。

只有实际未保存的名称、曲线、首尾参数或应用规则变化才会触发放弃确认。单独保存设备名称不会清除尚未保存的曲线或配置变化；真实编辑的保护仍保留。切换顶部页面保留草稿，但不保留输入框焦点。

本轮已在安装版实际验证：仅聚焦名称后在 Pencil／Wacom 之间来回切换无确认弹窗，焦点回到窗口；临时输入不同名称后切换会出现确认，丢弃后原名称与曲线保留。顶部配置／调试切换及返回正常，未保存测试文本没有写入配置。

## 切页动画（0.5.12）

窗口高度改为通过 NSAnimationContext 的非阻塞动画调整，不在导航点击回调里运行同步 `setFrame(... animate: true)`。可见窗口的切页和内容测量请求合并约 24 ms，取消过期请求，相同目标不重复启动缩放；保留约 0.2 秒缓入缓出、顶部锚定和恒定宽度。减少动态效果开启时直接调整。

快速连续切换以最后选中的页面为准。记住的是该页的目标高度，避免把动画中间尺寸或别页高度记入；动画完成后才恢复最终最小高度，旧动画完成通知不会覆盖新尺寸。关闭窗口会取消待执行的高度请求。页面内容仍即时切换，不额外叠加整页过渡动画。

本机回归中，连续四次切页回调旧实现耗时约 0.99 秒，新实现约 0.09 秒；这是点击回调耗时，不是画面帧率或动画总时长保证。另验证动画中途改选页面后的最终几何、最小尺寸、宽度和顶部位置。

## 实时压力条（0.5.13）

实时数值中的压力条改用直接绘制的 Canvas，和文本读取同一次已发布采样，不再使用系统任务进度控件。局部禁用动画事务，不添加平滑或补间；不改变监听发布上限（60 Hz），也不影响窗口高度动画。数值缺失时条形为空，文本与辅助功能值仍显示「未取得」，有效零压力单独显示为 0。过界或非有限值不会产生非法绘图尺寸。

相关离屏绘制回归在外层添加 1 秒动画，检查压力从 0.9 降至 0.1 后立即得到低值填充范围，并检查缺失、零、负值、NaN 与越界值；另检查调试页与自动高度布局。

## 移除未验证的实验功能（0.6.3）

已移除轨迹平滑、屏蔽触摸长按右键的界面、处理器、独立 tap 和诊断数据；不再采集完整 Quartz 事件快照。压力曲线、入锋、出锋仍可在每个应用中分别继承或覆盖。

旧配置中的 smoothing 字段与 smoothing 覆盖项会被移除；仅覆盖平滑的应用恢复为全部继承，混合覆盖保留曲线和笔锋。首次迁移先备份原 profiles.json/defaults.json，再原子保存 schema 6/4，未知的其它覆盖项仍视为无效配置而不覆盖文件。旧触摸屏蔽目标偏好不再迁移，并从当前偏好域清理。重启后仍需手动启用配置。
