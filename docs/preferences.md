# PenActor 0.4：设置与后台运行

参考本机 Mos 的菜单栏入口与工具栏分页布局，PenActor 将日常设置和输入诊断分开。后台处理仍在 PenActor 自身进程的输入线程中运行，没有安装额外系统服务或登录启动项。

## 五个页面

| 页面 | 用途 |
| --- | --- |
| 通用 | 启动行为、输入服务、权限、全局压力曲线与入锋 / 出锋默认值 |
| 应用 | 从运行中的应用或 `.app` 添加应用，按 bundle ID 保存继承、应用自定义或透传模式 |
| 硬件 | 为观察到的稳定身份新增、命名、保存、删除和启用配置，选择目标应用 |
| 调试 | 设备与会话元数据、监听器 / 接收状态、压力趋势、事件列表、映射输入输出和 JSON 导出 |
| 测试 | 独立笔迹画布及 Pencil 双击 / 挤压提示 |

菜单栏可打开设置、直接进入调试 / 测试、启停服务、暂停全部映射和退出。关闭窗口会保留监听与已启用映射，重新打开仍使用同一个设置窗口。应用不显示 Dock 图标；再次打开 `.app` 也可唤回设置。

`⌘⇧R` 暂停全部映射，`⌘⇧P` 启停输入服务。快捷键属于应用菜单，不是跨应用全局热键；绘画应用在前台时可用菜单栏执行暂停。停止服务会立即停止映射并恢复缓冲事件 / 按钮释放；重新启动服务不会自动启用映射。退出也执行同样的清理。

## 设置如何生效

先由已启用的硬件配置限定设备身份与目标应用。未配置、未启用或不在目标应用中的笔原样透传，设置全局默认不会自动接管 Wacom 等其他设备。

在匹配范围内依次处理：

1. 应用设为「此应用透传」：该应用全部笔压力透传，覆盖硬件自定义。
2. 硬件未选择「沿用应用 / 全局默认压力设置」：采用硬件配置自定义曲线与入锋 / 出锋。
3. 硬件沿用默认，且目标应用为「应用自定义」：采用应用默认。
4. 其余情况：采用全局默认。

每一层的曲线与入锋 / 出锋作为完整设置一起选择，不做参数叠加或连续多次映射。设备可在多个应用中获得不同默认值；需要同一应用对不同硬件使用不同响应时，取消硬件的「沿用默认」。

新硬件配置默认沿用默认值，初始全局值为线性、入锋 / 出锋关闭。旧版配置缺少 `usesDefaults` 时按 `false` 读取，保留原有曲线、入锋 / 出锋和目标应用限制。选择观察设备或设置页中的硬件不改变已启用配置。

界面使用显式保存。保存默认或修改已启用配置，从下一笔生效；当前笔画锁定开始时的设置。禁用硬件、暂停全部映射、停止服务立即生效。移除应用默认设置后，硬件中已有的目标应用仍保留并回退到全局默认；需要完全停止该应用映射，请设为应用透传或取消硬件目标应用勾选。

## 本地文件与重启

- `~/Library/Application Support/PenActor/profiles.json`：schema 3，保存硬件配置，兼容读取 schema 1 / 2。
- `~/Library/Application Support/PenActor/defaults.json`：schema 1，保存全局与应用设置。
- 启动时监听、启动时显示设置和调试设备自动切换保存在应用偏好设置中。

JSON 写入先校验再原子替换。重启保留设置，但映射始终关闭；后台运行不代表重启后自动修改输入。导出日志继续使用 schema 2，新增的 `mapping.defaults` 记录导出时的默认设置，与配置快照共同解释映射结果。

## 验证边界

自动化覆盖优先级、未选设备 / 应用透传、默认值笔画锁定、旧配置迁移、非法设置拒绝、持久化、导出和关闭窗口仍保持服务；五页均有原生 SwiftUI 离屏渲染检查。菜单栏真实交互和 Sidecar / PS / CSP 绘画仍需本机实测。指定应用屏蔽 Sidecar 触摸保持为 TODO，本次未实现。
